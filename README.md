# [Habit Hero](https://habittracker-42947.web.app/)


HabitHero is a beautiful, modern habit-tracking web app that helps you build life-changing habits with streaks, reminders, and a vibrant community feed.

# Backend
The API is a separate 
- Node.js/Express  
- MongoDB 
- project hosted on Vercel
# Features
- Tracking habit
- Add habit
- Powerful Streak System
- One-Click "Done" Mark
- Firebase Google & Email Login
- Toast Notifications
